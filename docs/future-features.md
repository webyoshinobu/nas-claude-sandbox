# 将来的な機能拡張案(Future Features)

## 目的

本プロジェクトはポートフォリオという性質上、機能範囲をMVP(必要最小限)に絞って実装している。本ドキュメントは、実装スコープには含めなかったが、実際のECサイトとして運用する場合に本来あった方がよい機能を、優先順位付けの根拠とともに整理したものである。

## 商品閲覧・検索まわり

| 機能 | 内容 |
|---|---|
| ソート機能 | 価格順、新着順、人気順など |
| ページネーション | 商品一覧の分割表示 |
| 関連商品表示 | 商品詳細ページで「同じ出品者の他の作品」「同カテゴリの作品」を表示 |
| お気に入り/ウィッシュリスト | ログインユーザーが商品を保存しておける機能 |
| 閲覧履歴 | 最近見た商品の表示 |

## 購入・決済まわり

| 機能 | 内容 |
|---|---|
| 返金機能 | 購入者からの返金申請、出品者/管理者による返金処理(Stripe Refund API連携)。デジタルコンテンツ特有の論点として、ダウンロード済みの場合の扱い(返金可否)をポリシーとして定める必要がある |
| クーポン・割引コード | 決済時に割引コードを適用 |
| ゲスト購入 | 会員登録なしで購入できる導線 |
| 複数決済手段 | Stripe以外の決済方法(PayPalなど)の選択肢 |
| 領収書/インボイス発行 | 注文詳細から領収書PDFをダウンロード |

## レビュー・評価

| 機能 | 内容 |
|---|---|
| レビュー・星評価 | 購入者が商品にレビューを書ける |
| Q&A機能 | 購入前に出品者へ質問できる |

## 会員・コミュニケーション

| 機能 | 内容 |
|---|---|
| パスワードリセット | メール経由でのパスワード再設定 |
| ソーシャルログイン | Google/GitHubアカウントでのログイン |
| 通知機能 | 購入完了・新着商品などのメール通知、またはアプリ内通知 |
| フォロー機能 | 気に入った出品者をフォローし、新着通知を受け取る |

## 出品者向け

| 機能 | 内容 |
|---|---|
| 売上グラフ・分析 | 期間別・商品別の売上推移をグラフ表示 |
| 在庫/販売数の上限設定 | 限定枚数販売など |
| 出品者プロフィールページ | 購入者が出品者の作品一覧・自己紹介を見られる公開ページ |
| 出品者評価 | 購入者からの出品者への評価 |

## 管理・運用

| 機能 | 内容 |
|---|---|
| 管理者用の全体管理画面 | 全ユーザー・全商品・全注文を横断的に確認できる管理者専用ロール |
| 通報機能 | 不適切な出品物を通報できる仕組み |
| アクセス解析 | Google Analytics等との連携 |
| SEO対策 | メタタグ、OGP画像、サイトマップ(sitemap.xml) |

## デザイン・UX

| 機能 | 内容 |
|---|---|
| ダークモード | UI切り替え |
| 多言語対応(i18n) | 英語/日本語切り替え。カナダでの就職活動という文脈では優先度を上げて検討する価値がある |
| ローディング/スケルトンUI | データ取得中の視覚的フィードバック |

## セキュリティ・信頼性

| 機能 | 内容 |
|---|---|
| レート制限(Rate Limiting) | ログイン試行やAPI呼び出しの過度な連続実行を防ぐ |
| CSRF/XSS対策の明示 | Spring Securityでの標準対応をREADMEに明記 |
| メールアドレス確認(Email Verification) | 実在するメールアドレスかの検証(なりすまし登録防止) |
| 画像アップロードのバリデーション | ファイルサイズ・拡張子・不正ファイルのチェック |
| 監査ログ(Audit Log) | 本プロジェクトの`created_by_source`/`updated_by_source`カラムはこの発展形の一部 |

## 今回のスコープに含めた理由・含めなかった理由(参考)

本プロジェクトでは、以下の観点でスコープを判断した。

- **含めたもの**:実務スキル(Java/Spring Boot、React/TypeScript、Stripe連携、JWT認証)を示すために技術的な広がりがあるもの、写真販売という商材の独自性を表現できるもの(ウォーターマーク処理、出品者ダッシュボード)
- **含めなかったもの**:実装コストに対してアピール効果が限定的なもの、今回の開発期間内での完成度を優先するために見送ったもの
